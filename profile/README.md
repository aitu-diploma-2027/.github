# Дипломные проекты 2027

Дипломные проекты студентов Astana IT University College.

## Как устроена работа

- У каждого студента свой репозиторий, созданный из шаблона [`diploma-template`](https://github.com/aitu-diploma-2027/diploma-template).
- Все задачи — на общей доске проекта «Дипломы 2027».
- Цикл задачи: **Бэклог → В работе → На проверке → Нужны правки → Готово**. Закрывает задачу только руководитель.
- Каждую неделю — комментарий в закреплённой задаче «Еженедельный статус».
- Код — в репозитории с первого дня. ИИ использовать можно, но любую строку своего проекта нужно уметь объяснить, а использование описать в `docs/ai-usage.md`.
